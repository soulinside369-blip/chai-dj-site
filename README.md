# Чай + DJ — сайт выездных чайных церемоний и DJ-сетов

Astro 5 (статика, без фреймворков) + `api/send.php` для заявок. Сделано агентством КЛЮЧ по ТЗ v2.0.

**Идея дизайна:** страница проживает вечер. Вверху — рисовая бумага и пар над гайванью (тихо, воздушно), при прокрутке пар превращается в звуковую волну, фон темнеет, включается свет и эквалайзер. Ниже — уголь, латунь и энергия танцпола.

## Как наполнять

Всё содержимое — в `src/data/*.json`. Править удобнее в админке: **`/admin/`** на сайте.

1. Создайте токен GitHub: Settings → Developer settings → Fine-grained tokens → доступ только к репозиторию `chai-dj-site`, права *Contents: Read and write*.
2. Откройте `https://<сайт>/admin/`, выберите «Sign In with Token» и вставьте токен.
3. Правьте цены, тексты, кейсы, фото. «Сохранить» = коммит в GitHub → сайт пересобирается сам за 1–2 минуты.

| Файл | Что внутри |
|---|---|
| `site.json` | контакты, рабочее время, первый экран, сцена вечера, шаги, «О нас», сертификаты, Метрика |
| `formats.json` | 4 формата: цены и коэффициенты калькулятора, программа, что входит |
| `calc.json` | ₽/км, генератор, порог «индивидуальный расчёт», вилка, города |
| `cases.json` | кейсы, отзывы, логотипы (только реальные и с согласия) |
| `faq.json`, `equipment.json`, `legal.json` | вопросы, оборудование и чайная карта, юр. тексты |

Пустые фото показываются тёплыми заглушками с подписью, какой кадр нужен. Поля в `[квадратных скобках]` — заглушки, к запуску их быть не должно.

## Проверка

```bash
npm ci
npm run check:calc   # пример из ТЗ: Чай + DJ, 50 гостей, 5 ч, 25 км = 73 000 ₽

```

## Выкладка

- **Превью** — GitHub Pages, при каждом пуше в `main` (`.github/workflows/pages.yml`). Формы там работают в демо-режиме: заявка не уходит, экран «Спасибо» помечен как демо.
- **Боевой хостинг с PHP** (Timeweb, Beget): задайте в репозитории переменную `SITE_URL` и секреты `FTP_SERVER`, `FTP_USERNAME`, `FTP_PASSWORD` — workflow «Выкладка на хостинг (FTP)» будет заливать `dist/` сам.
- На сервере один раз: скопируйте `api/config.example.php` → `api/config.php` и впишите токен бота, chat_id, домен и токен amoCRM, почту. В репозиторий этот файл не попадает.

## Заявки

`api/send.php`: номер заявки и срок ответа по Екатеринбургу → резервная запись в `api/private/leads.csv` → Telegram (по умолчанию без ПДн) → amoCRM (сделка, контакт, примечание с UTM) → копия на почту; если Telegram или CRM не ответили, письмо помечается «РЕЗЕРВ». Защита: ловушка для ботов, 1 заявка в 20 секунд с IP.

- [ ] Юрист проверил `legal.json`; уведомление в Роскомнадзор подано
- [ ] Карточки в Яндекс Бизнес и 2ГИС
